# Django Mailing Service

Курсовая работа: система email‑рассылок с разграничением прав, логированием и кэшированием.

## Функционал
- Создание, редактирование, удаление рассылок.
- Ручная отправка писем с логированием каждой попытки (`Attempt`).
- Динамический статус рассылки по времени.
- Роли: `user` (свои рассылки) и `manager` (все рассылки).
- Статистика по попыткам с кэшем 5 минут.
- Главная страница со сводными метриками.

## Соответствие требованиям курсовой
- Динамический статус: `Mailing.update_status()` в `core/models.py`.
- Логирование: модель `Attempt`, запись при отправке в `start_mailing`.
- Кэширование: `@cache_page(60 * 5)` на `user_stats`.
- Права доступа: миксин `OwnerOrManagerMixin`, проверки в `start_mailing` и CBV.
